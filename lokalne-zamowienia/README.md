# Lokalny projekt gier na zamówienie

Podgląd: http://127.0.0.1:4175/gry-na-zamowienie.html

Start z katalogu projektu: `node lokalny-kontakt/server.cjs`.

index.html zachowuje dotychczasową treść i zachowania. modern.css zawiera nową kolorystykę pomarańczową i granatową oraz układ sześciu etapów jako karteczki. Folder jest zapisany na gałęzi roboczej GitHub. Zmiany nie są wdrożone na publiczną stronę.
